ROJA DRINK - AUTOSAVE LANGSUNG KE FOLDER KOMPUTER

CARA MENJALANKAN:
1. Ekstrak folder ROJA_DRINK ke lokasi tetap, misalnya D:\ROJA_DRINK.
2. Pastikan Python 3 terpasang di Windows. Saat instalasi, centang "Add Python to PATH".
3. Klik dua kali MULAI-ROJA-DRINK.bat.
4. Browser akan membuka http://127.0.0.1:8765.
5. Tambah/edit/hapus menu seperti biasa. Tidak perlu memilih folder dari browser.

PENYIMPANAN:
Semua perubahan langsung ditulis oleh program lokal ke file:
ROJA_DRINK\nasimie-roja-data.json
File tersebut berada di folder aplikasi yang diekstrak. Ukuran file akan berubah saat data menu bertambah.

PENTING:
- Jendela hitam server harus tetap terbuka saat aplikasi digunakan.
- Untuk berhenti, tutup jendela hitam tersebut.
- Jangan membuka index.html langsung dengan double-click; selalu jalankan MULAI-ROJA-DRINK.bat.
- Buat salinan folder ROJA_DRINK secara berkala sebagai backup.
- Penyimpanan ini lokal di komputer tersebut, bukan sinkronisasi antarperangkat.
